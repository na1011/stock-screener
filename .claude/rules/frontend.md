# 프론트엔드 판단 기준

대상 사용자는 전문 트레이더가 아닌 초보~중급 투자자다. 이 전제가 화면 설계 판단의 기준이다. 폭넓은 지표를 다루면서도 사용자가 소외되지 않아야 한다.

- MUST NOT: 지표를 값만 나열하지 않는다. 초보 사용자는 그 값이 좋은 것인지 나쁜 것인지 알 수 없다. 지표가 무엇을 의미하는지, 어느 방향이 유리한 신호인지 함께 제공한다.

- MUST: 스크리닝 결과에 선정 이유를 노출한다. 프리셋 전략은 조건별로 획득한 점수를 확인할 수 있게 한다. 이유가 보이지 않는 결과는 신뢰를 얻지 못한다.

- MUST: 지지·저항 정보는 확정된 매매 신호와 시각적으로 명확히 구분한다. IMPORTANT — 사용자가 이를 매매 신호로 오해하면 실제 금전적 손실로 이어진다.

- MUST NOT: 진입가·손절가처럼 구체적인 매매 실행 가격을 제시하지 않는다. 이 서비스의 목적은 종목 발굴이다.

- MUST: 오류가 나도 문제 영역만 격리하고 화면 전체는 정상 동작하게 한다. 일시적 오류는 사용자 개입 없이 짧게 자동 재시도하고, 그래도 실패하면 사용자가 직접 재시도할 수단을 제공한다.

- 데스크톱과 모바일은 한 번에 노출할 수 있는 정보량이 다르다. 같은 화면을 축소해 보여주는 대신, 정보 밀도 높은 상세 분석과 빠르게 훑어보는 조회를 각 디바이스에 맞게 다르게 다룬다.

- MUST: 관리자 영역은 일반 사용자 화면과 명확히 구분하고, 권한 없는 사용자에게 노출하지 않는다.
