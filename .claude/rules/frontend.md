# 프론트엔드 규칙

- 대상 사용자는 초보~중급 투자자다. 지표를 값만 나열하지 않는다 — 의미와 유리한 신호 방향을 함께 제공한다.
- 스크리닝 결과는 선정 이유를 노출한다. 프리셋 전략은 조건별 획득 점수를 표시한다.
- 지지·저항 참고정보는 확정된 매매 신호와 시각적으로 구분한다.
- 오류는 화면 전체가 아닌 문제 영역만 격리한다. 일시적 오류는 자동 재시도하고, 실패 시 수동 재시도 수단을 제공한다.
- 데스크톱·모바일은 노출 가능한 정보량이 다르므로, 정보 밀도를 디바이스 특성에 맞게 다르게 다룬다.
- 관리자 영역과 일반 사용자 화면을 섞지 않는다.
