# 데이터 파이프라인 규칙

- 일부 종목 수집 실패로 전체 배치를 중단시키지 않는다 — 실패 종목만 건너뛰고 나머지는 처리한다.
- silent fail을 허용하지 않는다. 실패는 알림 체계(이메일+메신저)로 통지한다.
- 초기 적재(시세 2년·재무 3년)는 일일 갱신 배치와 분리된 1회성 작업으로 구현한다.
- 종목 유니버스 리밸런싱은 수동 개입 없이 자동으로 반영한다.
- 외부 소스(공공데이터포털·DART·Finnhub) 교체 시 영향 범위를 국소적으로 유지한다. 무중단 전환은 구현하지 않는다.
- 워치리스트 조건 충족 여부는 일일 배치에서 함께 확인하고 알림 체계로 통지한다.
- 외부 API 키·인증 정보는 환경변수로만 다룬다. 코드에 하드코딩하지 않는다.
