## 순서 — 미국 관문이 한 번으로 서려면

0. **설정 분리**: 주 설정 아래 묶음별 하위 설정(기본값 = 주 설정) — 설정이 하나면 「S0만 켠 상태」 같은 귀속 대조군이 main에 없다(P3a·P2 반증). 값 무변화라 무해한 선행 배포다.
1. **Writer 계약**: (a) 소스 행 null — **계약은 이미 있다**: `RawFinancialReport.assertedAbsent`(컬럼 단위 · 담을 자격 = 어댑터가 여러 판을 합쳐 판정했는가 · `fillMissing`은 어떤 컬럼이든 지운다).
   지금 미국 어댑터가 담는 컬럼은 `net_income` 하나(스윕 5,890행 · 2026-10-04)이고, **`mergeQ4`의 `mergedAbsence`가 `NET_INCOME`만 이어받는다** — 소스 행에 의도적으로 null을 내는 [S] 수정(K11 거르기 등)은
   그 컬럼을 담고 `mergedAbsence`를 일반화하는 것까지가 한 수정이다(안 하면 FILL_MISSING 재적재가 옛 값을 지킨다) · (b) 채움·새 라벨 뒤 파생층 과거 날짜([A30])는 매 평일 화해가 닫는다(ADR-0166) — 무효화를 거는 쪽으로 고치지 않는다 · (c) `overwritable()` ≤ 0 예외(주식수 0).
