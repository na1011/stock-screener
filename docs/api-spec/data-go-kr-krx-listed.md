# 공공데이터포털 — 금융위원회_KRX상장종목정보

**결론부터: 상장일이 없다. 이 서비스는 쓰지 않는다.** 실측으로 확인했으므로 다시 검토하지
않도록 근거를 남긴다.

- 출처: 공공데이터포털 오픈API 활용가이드 `금융위원회_KRX상장종목정보`(사용자 제공, 2026-08-10)
  + **같은 날 실제 호출 실측**
- 활용신청 승인됨. `DATA_GO_KR_SERVICE_KEY`로 정상 응답한다.

---

## 🔴 상장일자·상장폐지일자가 없다 — 도입 근거가 틀렸다

**받은 후보 목록(`공공데이터포털-api.txt`)은 이 API가 *"상장일자와 상장폐지일자 정보를
포함한다"*고 적었다. 틀렸다.** 응답 필드는 아래 일곱이 전부이고, 개발가이드의 응답 명세와
실제 응답이 **정확히 일치**한다(스펙에 없는 필드가 더 오지도 않는다).

```
basDt  srtnCd  isinCd  mrktCtg  itmsNm  crno  corpNm
```

실측(삼성전자, `likeItmsNm=삼성전자`):

```json
{"basDt":"20260807","srtnCd":"A005930","isinCd":"KR7005930003",
 "mrktCtg":"KOSPI","itmsNm":"삼성전자","crno":"1301110006246","corpNm":"삼성전자(주)"}
```

**이것이 DART 카탈로그와 같은 종류의 오판이다** — 목록·요약이 "무엇을 준다"고 적은 것을
실측 없이 믿었다. `dart-open-api.md` §9가 *"카탈로그는 엔드포인트의 존재를 답하지 실측을
대신하지 못한다"*고 적어 둔 그 자리이며, **이번에는 그 요약이 필드까지 지어냈다.**

## 쓰지 않는 이유 — 우리가 가진 것과 겹친다

| 필드 | 이미 어디에 있나 |
|---|---|
| `itmsNm`(종목명) · `mrktCtg`(시장) | 시세 전종목 조회가 준다(`data-go-kr-stock-price.md` §전종목 조회) |
| `srtnCd`(단축코드) | 종목코드에 `A` 접두어만 붙은 것 |
| `crno`(법인등록번호) | DART 매핑은 `corpCode.xml`이 이미 한다(`dart-open-api.md` §2) |
| `isinCd` · `corpNm` | 쓰는 곳이 없다 |

**새로 열리는 것이 하나도 없다.** 어댑터를 만들지 않는다.

## 그래도 남는 성질 하나 — 일별 스냅샷이다

`basDt`가 일자별로 쌓여 있어 **"그날 상장돼 있던 종목 목록"**이 된다(삼성전자 1,620행).
범위는 **2020-01-02부터로 시세·지수와 같다.**

이론상 **첫 등장일 = 상장일**(2020-01 이후 상장분에 한해)이고 **사라진 날 = 상장폐지일**이라
생존 편향 제거에 쓸 여지가 있다. **다만 `price_daily`가 이미 같은 성질을 갖는다** — 상장폐지
종목은 봉이 끊긴다. 그래서 이 API가 더 주는 것은 여전히 없다.

## U-05(상장 3년)는 이 서비스가 필요 없었다

**원본 명세 §U-05의 가공법이 상장일이 아니다:**

> `거래일 수 ≥ 750` (약 3년). **`ipoDate` 필드보다 실제 가격 시계열 길이로 판정할 것.**
> 재상장·스핀오프 케이스에서 `ipoDate`가 부정확한 경우가 많다.

`price_daily`에 **2020-01-02부터 1,620거래일**이 이미 들어 있고, 2026-08-10 기준 **320종목이
750봉을 넘는다**(13종목 500~749, 23종목 500 미만). **U-05는 지금 계산 가능하다.**

**경위와 오분류의 교훈은 ADR-0039 §단계 C에 있다.**
