# 공공데이터포털 — 금융위원회_KRX상장종목정보

**응답 필드는 일곱이 전부이고 상장일이 없다. 이 서비스는 쓰지 않는다.**

```
basDt  srtnCd  isinCd  mrktCtg  itmsNm  crno  corpNm
```

실측(삼성전자, `likeItmsNm=삼성전자`, 2026-08-10). 개발가이드의 응답 명세와 **정확히 일치**한다 —
스펙에 없는 필드가 더 오지도 않는다.

```json
{"basDt":"20260807","srtnCd":"A005930","isinCd":"KR7005930003",
 "mrktCtg":"KOSPI","itmsNm":"삼성전자","crno":"1301110006246","corpNm":"삼성전자(주)"}
```

- 출처: 공공데이터포털 오픈API 활용가이드 `금융위원회_KRX상장종목정보` + 같은 날 실제 호출
- 새로 열리는 것이 없어 어댑터를 만들지 않는다

## 함정

- **활용신청이 승인돼 키가 살아 있다.** 그래서 이 서비스는 포털 목록에 계속 보이고 정상
  응답도 한다 — **"상장일이 여기 있겠지"로 다시 오게 되는 유일한 이유가 그것이다.** 위 일곱
  필드가 전부다.
- **일곱 중 넷은 이미 가진 것이다.** `itmsNm`·`mrktCtg`는 시세 전종목 조회가(§전종목 조회),
  `srtnCd`는 종목코드에 `A`만 붙인 것, `crno`의 DART 매핑은 `corpCode.xml`이 이미 한다.
  `isinCd`·`corpNm`은 쓰는 곳이 없다.
- **일별 스냅샷이라는 성질은 실재하지만 그것도 새롭지 않다.** `basDt`가 일자별로 쌓여
  "그날 상장돼 있던 종목 목록"이 되고 범위도 2020-01-02부터로 시세와 같다. 첫 등장일을
  상장일로, 사라진 날을 상장폐지일로 쓸 여지가 있으나 **`price_daily`가 같은 성질을 갖는다**
  — 상장폐지 종목은 봉이 끊긴다.
- **U-05(상장 3년)는 이 서비스를 필요로 하지 않는다.** 원본 명세가 *"`ipoDate` 필드보다 실제
  가격 시계열 길이로 판정할 것"*이라고 명시한다(ADR-0039 §단계 C).
