# 기획 명세 변경 제안

`docs/stock-screener-project-spec.md`는 기획 정본이며 에이전트가 수정하지 않는다(CLAUDE.md). 실행 중 전제가 깨진 것을 발견하면 여기에 제안을 남기고, 사용자가 승인하면 그때 반영한다.

---

## 제안 1 — 미국 시장(S&P500)을 v1.1로 미룬다

- **상태**: 제안됨 (2026-08-06)
- **근거 ADR**: [ADR-0010](./adr/ADR-0010-defer-us-market.md)
- **관련 절**: §7(데이터·파이프라인 요구사항), §9(수용 기준), §10(범위 제외)

### 무엇이 깨졌는가

spec §7이 이렇게 적고 있다.

> 미국(S&P500) 종목의 시세 및 재무 데이터는 Finnhub를 통해 확보한다. (검토했던 다른 소스는 무료 티어에서 재무 데이터를 제공하지 않아 배제했다.)

2026-08-06 실제 키로 호출한 결과 **시세 부분이 성립하지 않는다.**

| 엔드포인트 | 실측 결과 |
|---|---|
| `/stock/candle` (과거 OHLC) | **HTTP 403** `{"error":"You don't have access to this resource."}` |
| `/stock/financials-reported` (재무) | HTTP 200 — 무료로 정상 동작 |

즉 spec이 Finnhub를 고른 이유("무료 티어에서 재무를 주는 유일한 소스")는 **여전히 유효하지만**, 같은 소스로 시세까지 받는다는 전제만 깨졌다.

### 대안을 전부 검토했으나 각각 문제가 있다

| 소스 | 실측/조사 결과 | 판단 |
|---|---|---|
| Stooq | JS proof-of-work 챌린지로 스크립트 접근 불가 | 불가 |
| Yahoo Finance(비공식) | 첫 요청부터 HTTP 429 | 불가 |
| Alpha Vantage 무료 | 25 req/day → 500종목에 20일 | 불가 |
| EODHD 무료 | 20 req/day | 불가 |
| Tiingo 무료 | 수치는 충족하나 ToS가 **"Internal Use Only"** | **spec §2의 "지인 공유"와 충돌** |
| massive(구 Polygon) 유료 | ToS 명확, 하루 1콜로 전 종목 | **spec §2의 "비용 최소화"와 충돌** |
| SEC EDGAR | 무료·공식·키 불필요. 단 **재무 전용** | 시세 대안 아님 |

무료를 유지하면 ToS를 어기고, ToS를 지키면 비용이 든다. 어느 쪽도 현재 spec과 정합하지 않는다.

### 제안하는 변경

**§7** — 미국 데이터 소스 문장을 다음 취지로 수정:

> 미국(S&P500) 종목 지원은 v1.1로 미룬다. Finnhub 무료 티어가 과거 시세 제공을 중단해(2026-08 실측) v1 범위에서 제외한다. 재무는 Finnhub 또는 SEC EDGAR로 확보 가능하나, 시세 없이는 기술적 지표와 PER·PBR을 계산할 수 없다.

**§9** — 수용 기준의 "코스피200·코스닥150·S&P500" 을 "코스피200·코스닥150"으로 수정.

**§10** — 범위 제외에 항목 추가:

> **미국(S&P500) 시장 지원**: 무료로 접근 가능한 미국 일별 시세 소스가 확인되지 않았다. 유료 소스 도입 또는 ToS가 허용하는 무료 소스가 확인되면 v1.1에서 추가한다. 데이터 소스 계층이 포트로 분리되어 있어 어댑터 하나를 추가하는 비용으로 붙는다.

### 이 변경이 위험하지 않은 이유

- 스키마·유니버스 구조는 미국을 **이미 수용한다**(`universe.code = 'SP500'`, `market.code = 'US'`가 V1에 있다).
- 포트(`PriceDataSource`·`FinancialDataSource`)가 그대로 있어 어댑터만 추가하면 된다.
- 스크리닝 엔진·지표 계산·워치리스트는 시장에 무관하다.
- 되돌리는 비용이 "어댑터 1개 + 시드 CSV"로 한정된다는 것이 ADR-0006이 만든 구조의 실증이 된다.

### 승인이 필요한 이유

이것은 구현 판단이 아니라 **제품 범위 축소**다. spec §9의 수용 기준을 미달 상태로 v1을 끝내겠다는 뜻이므로, 에이전트가 단독으로 결정할 사안이 아니다.

**대안을 원하시면**: massive 최저 유료 티어를 쓰면 미국을 v1에 포함할 수 있다. 그 경우 §2의 "인프라 운영 비용 최소화"에 월 구독료가 예외로 추가되어야 한다.
