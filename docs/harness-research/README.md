# 하네스 조사 보고서 (stock-screener 제품과 무관)

이 폴더는 **stock-screener 제품과 관계없는 작업**이다. 다른 팀 프로젝트(WES 구축)에 쓸 에이전트 하네스의 뼈대를 고르기 위한 조사 보고서를 원격에서 읽으려고 이 저장소에 두었다. 이 저장소의 spec·ADR·progress·phase 판정과 연결되지 않으며, 그것들의 근거로 인용하지 않는다.

## 이 폴더에 없는 것

- 근거 노트(보고서가 인용한 원문 발췌·URL)는 작성 기계의 `~/dev/harness-kit/research_notes/`에만 있다. 보고서의 각 주장에는 URL과 날짜가 달려 있다.
- 폐기된 1차안(stock-screener 하네스를 모듈로 떼어내는 계획)은 싣지 않았다.
