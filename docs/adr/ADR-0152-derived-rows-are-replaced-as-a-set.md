# ADR-0152. 우리가 만든 행은 판 세트째 바뀐다

## 결정

`RawFinancialReport`에 **`derived`**를 두고, 재적재 모드에서 **유도 라벨의 저장 판을 이번 세트로
교체한다** — 세트에 없는 공시일의 판은 지우고, 컬럼 단위로는 **소스가 안 준 값을 비운다.**

## 규칙

- **MUST: 유도한 행에는 `derived = true`를 준다.** 유도 자리는 둘이고 둘 다 이름이
  `deriveFourthQuarter…`다. 호환 생성자가 기본 `false`를 주므로 **컴파일러가 묻지 않는다.**
- **MUST NOT: 소스가 준 행에 이 처리를 하지 않는다.** 거기서 컬럼이 빠진 것은 「그 판이 그
  컬럼을 안 실었다」이지 「값이 없다」가 아니고, 판이 빠진 것은 「그 공시가 없다」가 아니다.
  적재된 원자료는 되돌리지 않는 것이 규칙이다(ADR-0071).
- **MUST NOT: 적재 창을 좁힌 채 돌리지 않는다.** 창 밖 세대는 이번 세트에 안 들어오고, 그러면
  회수가 **멀쩡한 옛 세대를 지운다.** ADR-0145가 창을 안 좁히는 이유에 이 축이 하나 더 붙는다.
- **MUST: 회수 뒤 `is_latest`를 다시 세운다.** 최신본이 지워질 수 있고, 부분 유니크 인덱스가
  「정확히 하나」를 요구한다. **전부 내린 뒤 하나만 올린다** — 한 문장으로 바꾸면 중간 상태가
  인덱스에 걸린다.
- **MUST NOT: `APPEND_ONLY`에서 회수하지 않는다.** 일일 사슬이 그 모드이고, 거기서 판을 지우면
  장 마감 갱신이 원장을 조용히 줄인다.

## 검증

```bash
./gradlew test --tests "*FinancialWriterTest.derivedRowClearsWhatTheNewRuleCannotMake*"
./gradlew test --tests "*FinancialWriterTest.retractsDerivedRevisionsThatTheNewRuleNoLongerMakes*"
```

**이 결정은 premise를 두지 않는다.** 재는 것이 「지금 저장이 어떤가」가 아니라 **「규칙을 바꿨을
때 따라오는가」**이고, 그것은 질의로 답할 수 없다 — 규칙을 바꿔 돌려 봐야 나온다. 실제로 그
사실이 **이 결정을 만든 계기**다(아래).

## 배경

**두 번 같은 자리에 걸렸고, 두 번 다 「잡은 성공」으로 지나갔다.**

1. ADR-0151의 첫 판(태그 일치 게이트)을 넣고 전 종목을 재적재했다. 잡은
   **「정정 0 · 채움 0 · 교정 0」**으로 끝났고 **미국 4분기 음수 45행이 한 행도 안 줄었다.**
   원인은 `fillMissing`이 **NULL만 채우고 값을 NULL로 덮지 않는** 것이었다.
2. 컬럼을 지우게 고친 뒤, 이번에는 **세대가 틀린 판 자체**가 남았다. `writeOne`이 **더 이른
   공시본을 건너뛰므로**, 새 규칙이 내는 옳은 세대(`AIG` 2022의 2024-02-14 · 11,845)는
   저장에 닿지 못하고 옛 규칙이 만든 −12,609가 `is_latest`인 채 남는다.

**공통 원인 하나다 — 저장이 「우리가 만든 행」을 「소스가 준 사실」과 똑같이 다룬다.** 소스의
판은 되돌리면 안 되지만 **우리 계산은 규칙이 바뀌면 따라와야 한다.**

## 버린 대안

- **`financial_statement`에 `derived` 컬럼을 더한다** — 저장된 행이 우리 것인지 알 수 있지만
  **필요가 없다.** 유도는 소스가 그 분기를 직접 줄 때 아예 건너뛰므로, **우리가 유도한 라벨의
  저장 판은 우리 것**이다. 컬럼을 더하면 마이그레이션과 기존 행의 소급 표시가 따라온다.
- **옛 행을 손으로 고친다**(ADR-0126 §규칙의 「수리는 값으로」) — 이번 25건은 고칠 수 있어도
  **다음 규칙 변경에서 같은 일이 다시 생긴다.** 사람이 매번 따라가는 것은 기제가 아니다.
- **유도 결과를 `financial_statement`가 아니라 별도 표에 둔다** — 소비자가 전부 이 표를 읽으므로
  읽기 경로가 둘로 갈린다. 유도값은 **재무 사실과 같은 자리에 있어야** TTM 합이 성립한다.

## 결과

**닫힌 것** — 유도 규칙을 고치면 옛 유도 결과가 **컬럼 단위로도 판 단위로도** 따라온다.

**어려워지는 것**

- **회수가 `invalidate`를 부른다.** 규칙을 바꾼 첫 재적재는 그 종목들의 지표를 보존 창에서
  지우므로 **백필이 반드시 뒤따라야 한다.**
- **세트가 곧 진실이라는 계약이 생겼다.** 어댑터가 어떤 이유로든 유도를 덜 내면 저장이 그만큼
  줄어든다 — 위 「창을 좁히지 않는다」가 그 계약의 대가다.
