# ADR-NNNN. 짧은 결정 제목

## 결정

무엇을 하기로 했는가. 한두 문장으로.

## 규칙

이 결정이 코드에 부과하는 제약을 검증 가능한 단정으로 쓴다. 산문 서술 대신 지킬 것/하지 말 것을 명시한다.

- MUST: (반드시 지켜야 하는 것)
- MUST NOT: (하지 말아야 하는 것)

## 검증

이 결정이 지켜지는지 확인하는 실행 가능한 명령. 예: `rg "new RestTemplate" src/main/java` 가 아무것도 반환하지 않아야 한다.

자동 검증이 불가능한 결정이면 "이 결정은 자동 검증 대상이 아니다"라고 명시한다.

**결정이 *지켜지는가*가 아니라 *아직 옳은가*를 묻는 명령이면 펜스를 `premise`로 태그한다.** `check-premises.sh`가 세션 시작에 그것만 돌린다. 선택이며, 관측할 수단이 없으면 태그하지 않는다.

````markdown
```premise 한 줄짜리 라벨
psql -d db -At -c "SELECT CASE
  WHEN count(*) = 0 THEN '잴 것이 없었다 — 대상이 하나도 없다'
  WHEN <전제가 참> THEN 'OK ' || <잰 값>
  ELSE <무엇이 어긋났는지> END FROM ..."
```
````

계약이 넷이다. **`OK`로 시작하면 침묵**, 다른 출력은 발견, **출력이 없으면 판정 불가**, 종료 코드 ≠ 0도 판정 불가다.

- **MUST NOT: psql 인자 안에 역따옴표를 쓰지 않는다 — SQL 주석 안이라도 그렇다.** 인자가
  큰따옴표이므로 bash가 그 안을 **명령 치환으로 실행한다.** 실제로 ADR-0135의 전제가 SQL 주석에
  적은 한 구절 때문에 저장소 루트에 `0`이라는 이름의 파일을 만들고 있었다(그 구절에 부등호가
  있어 리다이렉션이 됐다 · 2026-09-23 생성 · 세션마다 다시 잘렸다 · 전제 145개 중 하나).
  **증상이 파일 하나뿐이라 어떤 검사도 안 잡는다** — 치환된 명령이 다른 것이었으면 더 나빴다.
  식별자를 인용하려면 `「」`나 따옴표 없는 평문을 쓴다.
- **MUST: 펜스 본문의 주석은 `#`다.** 본문은 bash로 실행되므로 SQL 주석 `--`를 psql 인자 **밖에** 적으면 bash가 옵션으로 읽어 `rc=2`로 죽고, 그 전제는 붉음도 초록도 아닌 **무판정**이 된다 — 조용해서 더 나쁘다(실측).

- **MUST: 모집단을 쿼리가 스스로 단정한다.** 0행은 출력이 없어 무판정으로 잡히지만, 그것은 "왜 못 쟀는지"를 말해 주지 않는다. `count(*) = 0`을 따로 답하지 않으면 지표가 통째로 사라진 상태와 정상을 구분하는 근거가 남지 않는다.
  - **모집단이 비는 경우가 둘 이상이면 그것도 가른다.** "지표가 없다"와 "지표는 있는데 조인 대상이 없다"를 한 갈래로 묶으면, 있는 것을 없다고 **단정하는** 문장이 나온다 — 침묵보다 나쁘다. ADR-0036이 실제로 그랬다.
- **MUST: 모집단을 결정의 술어와 같은 것으로 잡는다 — 「지금 우연히 같은 것」으로 잡지 않는다.**
  `JOIN stock`이 편입 종목과 같은 집합인 동안은 둘이 구분되지 않지만, 그 우연이 깨지는 날
  펜스가 **아무것도 안 틀렸는데 운다.** 실제로 셋이 그렇게 울었다(ADR-0036·0066·0068 —
  복원이 유니버스 밖 종목 109개를 `stock`에 넣자 중앙값이 2.532조에서 1.712조로 내려갔다).
  **가르는 질문은 「이 수를 만드는 집합의 정의가 무엇인가」**이고, 답이 결정의 것과 다르면
  같게 고친다. 우연에 기댄 펜스는 **깨지기 전까지 초록이라 검토에서 안 걸린다.**

- **MUST NOT: 되돌릴 수 없는 명령을 넣지 않는다.** `guard-destructive.sh`가 심사해 거부하지만, 거부는 판정 불가이므로 그 전제는 영영 답을 주지 않는다.
- **MUST NOT: 의도한 동작에 우는 펜스를 만들지 않는다.** 모집단을 좁히지 않으면 **일부러 값을 안 내기로 한 대상**까지 세어 매 세션 거짓 발견이 난다. 거짓 발견은 침묵보다 나쁘다 — 다음 세션이 그것을 회귀로 읽고 멀쩡한 결정을 되돌리러 간다. **모집단에서 뺀 근거를 쿼리 옆에 적는다.** 열거는 나중에 늘어나므로, 값 목록을 박아 넣었으면 **그 목록이 자라는 자리**도 함께 적는다.
- 읽기 전용으로 붙는다(`PGOPTIONS`가 강제). 상한은 **둘이고 질의를 실제로 자르는 것은 안쪽이다** — `statement_timeout`이 질의를 죽이고, `per_limit`의 alarm이 그 바깥에서 프로세스를 죽인다. **값은 여기 적지 않는다**(`check-premises.sh`가 정본이다). 그 둘은 `per_limit > PGCONNECT_TIMEOUT + statement_timeout`을 지켜야 해서 정해진 것이라 숫자만 보고 바꾸지 않는다.

## 배경

무엇이 이 결정을 필요하게 만들었는가. 한 문단으로 압축한다.

**MUST NOT: 정정 이력을 쌓지 않는다.** 결론이 바뀌면 **본문을 고치고**, 다음 세션이 같은 오판을 반복할 수 있는 것만 남긴다. 뒤에 반박을 덧붙이면 무효가 된 문장이 문서 안에 살아남아 근거로 인용된다. 판단 기준은 `.claude/rules/doc-facts.md`에 있다.
