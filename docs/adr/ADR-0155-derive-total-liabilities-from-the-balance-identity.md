# ADR-0155. 총부채를 재무상태표 항등식으로 유도한다

## 결정

소스가 `Liabilities`를 안 내면 **총부채 = 총자산 − 총자본 − 중간지분**으로 유도한다.
**근거가 확실한 총자본으로만** 유도하고(직접 낸 값이거나 지배주주 자본 + 비지배지분),
폴백 총자본으로는 하지 않는다.

## 왜 — 지금 네 지표가 통째로 꺼져 있다

**재적재 뒤 `US_TOP1000` 최신 FY 1,000종목 중 225(22.5%)의 `total_liabilities`가 비어 있다.**
그 종목에서 `DEBT_RATIO`·`ALTMAN_Z`·`ALTMAN_Z_DOUBLE_PRIME`·`NCAV_TO_MARKET`이 **하나도 안 난다.**

**원장의 한계가 아니다.** 재무상태표는 정의상 `자산 = 부채 + 중간지분 + 자본`이고, 우리는
자산과 자본을 이미 갖고 있다. **유도를 안 한 자리다.**

## 이 결정이 다른 점 — 「없는 값」을 「값」으로 바꾼다

ADR-0153·0154는 **틀린 값을 옳은 값으로** 바꿨다. 이것은 **없던 값을 만든다.**
`docs/progress.md`가 *"「틀린 값」이 「없는 값」보다 먼저다 — 없는 값은 사용자가 알지만
틀린 값은 모르고 쓴다"*로 적은 그 축의 **반대쪽**이므로, **틀릴 크기를 먼저 쟀다.**

**실측(2026-09-15 · 표본 47 · `.factcache/`)**

| 질문 | 답 |
|---|---|
| 부채가 없는 잔액 칸 중 유도로 닫히는 것 | **611 / 813 (75.2%)** |
| 답을 아는 1,845칸에서 이 산수가 0.1% 이내 | **1,729 (93.7%)** |
| 벗어난 116의 분포 | **1% 이내 76 · 1~5% 33 · 5% 초과 7** |
| 5% 초과 7의 정체 | **6이 `YUM`**(자본잠식이라 분모가 작다) · 1이 `KMX` |
| 중간지분을 안 빼면 | **87.0%**로 떨어진다 — 그 6.7%p가 메자닌이다 |

**98.1%가 1% 이내**다. 「없는 값」이 주는 정보가 0인 것과 견주면 이쪽이 낫다.

## 규칙

- MUST: **직접 낸 값이 언제나 이긴다**(ADR-0104).
- MUST: **근거가 확실한 총자본으로만 유도한다**(`foundedTotalEquity`). `TOTAL_EQUITY`의
  마지막 폴백은 **지배주주분일 수 있고**, 그것으로 빼면 부채가 비지배지분만큼 부푼다 —
  **값이 그럴듯해 화면에서 안 드러난다.**
- MUST: **중간지분을 뺀다.** 상환가능 비지배지분·임시자본은 부채와 영구자본 **사이**에
  앉는다. 없으면 0으로 본다(위 수가 그 가정 위에서 재졌다).
- MUST: **`자산 = 부채 + 자본` 펜스의 분모가 이 결정으로 바뀐다는 것을 안다.** 유도한 행에서는
  항등식이 **정의상 참**이라 안 걸린다 — 저장에 유도 여부가 없어 **「소스가 준 행만 세라」는
  실행할 수 없다.** 그래도 펜스는 유효하다: **걸리는 행은 여전히 전부 소스가 준 행**이라
  진짜 파괴만 잡는다. **바뀌는 것은 분모이므로 기준선을 이 결정 뒤에 다시 잰다.**

## 검증

```bash
# 폴백 총자본으로 부채를 유도하는 경로가 없다 — foundedTotalEquity만 쓴다
rg -n -A 14 "private static BigDecimal totalLiabilities" \
  src/main/java/com/stockscreener/pipeline/datasource/us/SecEdgarFacts.java | rg "totalEquity\(v\)"
# 위가 아무것도 안 내야 한다.

# 중간지분이 저장 컬럼으로 새지 않는다
rg "mezzanine|MEZZANINE" src/main/java/com/stockscreener/pipeline/datasource/RawFinancialReport.java
```

## 버린 대안

- **`LiabilitiesCurrent` + `LiabilitiesNoncurrent`로 유도한다** — 실측에서 **813칸 중 2칸**만
  그 둘을 함께 갖는다(0.2%). 항등식 쪽이 375배 넓다.
- **유도하지 않고 둔다** — 「틀린 값보다 없는 값이 낫다」가 이 자리에는 안 선다. **없는 값도
  사용자에게 도달하지 않는다**(지표가 아예 안 뜬다). 그리고 98.1%가 1% 이내다.
- **부채까지 유도되면 항등식 펜스가 무의미해지니 유도를 막는다** — **펜스를 위해 데이터를
  나쁘게 두는 것**이다. 펜스 쪽을 「소스가 셋을 다 준 행」으로 좁히면 된다(§규칙).
