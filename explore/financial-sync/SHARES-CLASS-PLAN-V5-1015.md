## 1. 값

### 1a. 두 개념 (v2 그대로)
- **N_L**: 발행사 주식수를 줄 L 단위로 센 시점 값 — 순위 · `MARKET_CAP` · 주당 지표 · `ShareBasisDeriver` · 배당 총액.
- **n**: 그 공시가 스스로 닫는 EPS 분모(평균) — **주식수 비 지표 셋**(`SHARES_GROWTH_3Y` · `EPS_GROWTH_TTM_YOY` · `EPS_CAGR_5Y`)의 두 끝(11).
- **C_L**: 그 줄 클래스의 유통 주식수 — 회전율(v2 §1d).

### 1b. 대상 (5)
- 클래스 축 앵커 = 표지 dei(`EntityCommonStockSharesOutstanding`)가 클래스 구성원에 실린 정기 공시. 축 없는 dei 공시와 앵커 아닌 공시는 지금 경로 그대로.
- 로더(6): 클래스 축 맥락 + 같은 사실을 다른 이름으로 단 축(위 표 6). 축 뜻으로 고르고 종목 갈래는 없다.

### 1c. 분모 n (`rule7.py`)
- 기간·태그·갈래(A/A0/M/B)는 v2 §1b. 폐합 허용 = 원장이 밝힌 분자면 선언 정밀도, 대용이면 + τ·|분자|.
- 상장 클래스 매핑: 기호 일치 → 기호 글자 → 제목의 「Class X」 → **제목 낱말 = 구성원 이름 낱말이 하나로만 맞을 때**(v5 · 「Voting Common Shares」 = `VotingCommonStockMember` — `JEF` 2026-10이 이것으로 섬). 기호는 **전체 일치**만 본다(「JEF」가 사채 기호 「JEF 27A」에 낱말로 들어 있다).
- 단위 복원(4): 폐합 실패면 분모 ×10^±3,±6 · EPS ×10^±2,±3 · 분자 ×10^±3,±6을 다시 폐합해 **같은 공시의 시점 총량 T와 |log10(n/T)| < 1**인 후보가 하나일 때만 받는다. T가 없으면 실패.
- 부호 어긋남(9) = 검사 불가 → 값을 받고 센다.
- 실패의 출처(7): 원장 어긋남 / 대용 한계 / 원장이 안 줌(분모·기간 없음 · 매핑 실패).
- 20-F·40-F: B 갈래 · 시점 합을 안 건다(ADS 비율을 원장이 안 준다 · v2).

### 1d. 값 N — 원장이 참여를 확인하면 시점, 아니면 평균
공시마다 처음 서는 것. 10-Q의 기준 n_ref = n, 10-K = Q4 n(① Q3 10-Q 9개월 누적 · ② 3개월 셋 · ③ 없으면 UNRESOLVED — v4 그대로). 비교마다 공시일까지의 분할 계수를 곱한다.
1. **층 a/b**(원장이 집합 S를 말함): S 전원이 표지에 있으면 N = Σ_S 표지_k · e_k/e_L. **완전성(3)**: S의 중점 합 ÷ n ≤ τ_rf(중점이 없으면 N ÷ n_ref ≤ τ_c). 실패면 평균으로 내림.
2. **층 c P-c**(시점 값이 아직 안 섰으면 언제나): T = Σ 전 클래스 표지, |T/n_ref − 1| ≤ τ_c → N = T.
3. **층 c′ 롤포워드(10)**: 원장 집합을 쓸 수 없을 때(S 없음 · 표지와 이름 불일치)만. 중점 합 ÷ n ≤ τ_rf인 부분집합이 **유일하면** N = Σ_S 표지. 둘 이상 맞으면 안 고른다(작은 클래스가 τ_rf 안에 숨는 꼴 · 창 밖 포함 90판).
4. **평균**: N = n_ref. 첫 앵커 가드(기준 없음 → 숨기고 그 값을 다음 기준으로) · 전이 확인 |n_ref/(기준 · 분할) − 1| > τ → 숨김. **기준 = 바로 앞 정기 공시의 n(8)**.
- 전이 확인의 근거(**재지 않음** — 분기 안 선형 변화를 가정한 산수): 평균이 시점에 뒤처지는 폭은 그 분기 변화의 절반쯤이다. 변화가 τ(5.4%) 안이면 뒤처짐이 τ_c(5.2%) 안이라 시점 값과 같은 허용이다. 넘으면 평균은 「억지 근사」라 미표시한다 — 성장 발행사(`MSTR` 294 → 334M · `VNOM` · `GLXY`)의 숨김은 결함이 아니라 이 규칙이 의도한 것이다.
- 시점 값에는 전이 확인을 걸지 않는다.

### 1e. 숨김 · 보류 · 제외 — 그날까지 공시된 판만 본다 (1 · 14 · 7)
- **판 숨김**: UNRESOLVED 판은 그 공시일부터 다음 판까지 그 CIK의 모든 줄의 N_L을 비운다. 지표는 앞 판으로 내려가지 않는다 — 기존 장치 하나에 태운다: 판의 기저 `UNRESOLVED`면 `sharesOf`가 값을 안 낸다(`FinancialMath.java:659` · ADR-0162).
- **편입 보류(1)**: 리밸런싱 asOf의 최신 정기 판이 숨김이고 **그 앞 정기 판이 통과**면 「보류」 — 현 편입이면 자리를 지키고(값은 빈다), 비편입이면 후보가 못 된다. 정원은 1,000 − 보류 수로 순위에서 채운다.
- **보류 끝(14)**: 앞 정기 판도 숨김이면 보류가 아니다 → 순위에 없음 → 편출. 공급(ADR-0178)이 후보의 다음 공시를 먹이므로 통과 판이 오면 그다음 토요일에 순위로 돌아온다. 연차 제출자도 같은 규칙이다.
- **발행사 제외**(사용자 10-14 「**원장 자체가** 이랬다 저랬다 하는 종목은 … 빼버리는 게 나을 수도」): d일 기준 지난 255거래일 안에 **원장 어긋남**(7) 구간이 둘 이상 시작했으면 d일에 CIK째 뺀다 — 사이에 통과 판이 와도 안 돌아온다. 우리 대용의 한계(전이 · 첫 앵커 · 대용 분자 · 매핑)는 묶지 않는다.
